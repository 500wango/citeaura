2. Action tickets with acceptance gates

Every recommendation has an owner, an evidence link, and a checker that can reopen the ticket after a regression.

GEO-014 · P0Checker · robots

Allow answer-engine crawlers on public docs

Why: GPTBot and OAI-SearchBot are blocked at root. Acceptance: re-crawl confirms no blocking directive.

GEO-021 · P1Checker · JSON-LD

Expose canonical product facts

Why: the product page has no structured entity graph. Acceptance: JSON-LD parses and matches approved facts.

GEO-025 · P1Checker · llms.txt

Publish a reviewed machine-ingestion file

Why: no llms.txt was found. Acceptance: the file is reachable and linked from the delivery manifest.

GEO-031 · P2Checker · citation

Close the highest-value citation gap

Why: two target prompts cite third-party pages first. Acceptance: a comparable re-sample records the before/after delta.

3. Delivery and verification

The final pack contains an audit report, execution plan, ticket log, acceptance checklist, draft risks, and build map. The pack is marked diagnostic-ready until implementation evidence is complete.
