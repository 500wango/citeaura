Perplexity AI combines live web indexation with LLM synthesis models (Sonar and Sonar-Pro). To earn citation cards rather than being summarized through third-party intermediaries, websites must understand how PerplexityBot crawls, extracts, and anchors factual claims.

How Perplexity's RAG Architecture Selects Sources

Traditional search engines calculate PageRank and keyword density across pre-indexed documents, serving a list of blue links for the user to evaluate. Perplexity operates an automated Retrieval-Augmented Generation (RAG) pipeline that executes in real-time:

  1. Query Decomposition: When a user asks "What are the best GEO platforms for B2B SaaS and how do their pricing plans compare?", Perplexity breaks the query into multiple sub-queries sent concurrently to web search index APIs (including Brave Search and internal web clusters).
  2. Live Crawl & Snippet Retrieval: The top 10–20 candidate pages are fetched on demand. The crawler extracts headings, paragraph text, and structured data while discarding advertising scripts, complex client-side bundles, and navigations.
  3. Context Window Insertion: Extracted document passages are assembled into the LLM context window alongside the user prompt.
  4. Numerical Citation Binding: As the model generates the synthesized response, its internal attention heads attach bracketed citation markers (e.g., [1], [2]) pointing back to the specific source URLs whose tokens justified the factual sentence.

The Difference: Mentioned vs. Cited

A critical metric measured by CiteAura is the distinction between a Brand Mention and an Official Domain Citation:

Attribution Type How It Happens The SEO Consequence CiteAura Diagnostic Action
Mentioned Only (No Link) Model mentions your name from pre-trained parametric memory or an aggregator review, but cites a directory (e.g., G2, Reddit). Zero direct referral traffic; risk of displaying outdated pricing or competitor bias. Create structured brand fact library and entity anchors on canonical product pages.
Official Citation (Direct Link) Perplexity fetches your canonical URL, verifies facts directly, and places your domain in the numbered citation array. High-intent qualified referral clicks and verified entity ownership. Verify robots.txt access and ensure high extractability on canonical pricing and feature tables.

Configuring robots.txt for Perplexity

Perplexity utilizes two primary user-agent tokens defined under RFC 9309:

  • PerplexityBot: The automated background crawler used for web indexation and content caching.
  • Perplexity-User: The user-initiated real-time retrieval agent that fetches URLs when a user asks a live question in Perplexity Pro.
# Recommended robots.txt configuration for Perplexity
User-agent: PerplexityBot
Allow: /
Disallow: /admin/
Disallow: /app/
Disallow: /api/

User-agent: Perplexity-User
Allow: /
Disallow: /admin/
Disallow: /app/

Warning: Blocking PerplexityBot while allowing other bots will ensure your competitor's marketing copy is cited when users ask comparison queries about your software.
