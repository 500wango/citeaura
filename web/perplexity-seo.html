How Perplexity's RAG Architecture Selects Sources

Perplexity uses a Retrieval-Augmented Generation (RAG) workflow: relevant web pages are retrieved, extracted, and supplied to a language model that produces an answer with source links. Perplexity has not published a complete candidate count, ranking order, or retrieval timing, so separate documented behavior from implementation details that remain undisclosed.

  1. Query Handling: Perplexity may reformulate or decompose a question into related searches. The number of sub-queries, search suppliers, and ranking order are not fully documented.
  2. Live Fetch and Extraction: When a page is retrieved, the system extracts readable text and links. The exact number of candidate pages, selection thresholds, and parser behavior is not public.
  3. Context Assembly: Selected passages are supplied to a language model as context. Context size and passage selection can vary by product and query.
  4. Citation Display: The answer surface returns numbered source links. How the model binds a specific sentence to a source is not publicly specified.

The Difference: Mentioned vs. Cited

A critical metric measured by CiteAura is the distinction between a Brand Mention and an Official Domain Citation:

Attribution Type How It Happens The SEO Consequence CiteAura Diagnostic Action
Mentioned Only (No Link) Model mentions your name from pre-trained parametric memory or an aggregator review, but cites a directory (e.g., G2, Reddit). No direct link from that answer; referral and attribution are not guaranteed. Create structured brand fact library and entity anchors on canonical product pages.
Official Citation (Direct Link) The answer links to your canonical URL and records the citation at the answer level. A direct referral opportunity; users can inspect the cited page for current facts. Verify robots.txt access and ensure high extractability on canonical pricing and feature tables.

Configuring robots.txt for Perplexity

Perplexity documents two user-agent tokens with different roles:

  • PerplexityBot: Used to surface and link websites in Perplexity search results. Perplexity says it is not used to crawl content for AI foundation models.
  • Perplexity-User: A user-triggered fetcher that may visit a page to answer a question. It is not used for background crawling or training, and Perplexity says it generally ignores robots.txt rules.
# Recommended robots.txt configuration for Perplexity
User-agent: PerplexityBot
Allow: /
Disallow: /admin/
Disallow: /app/
Disallow: /api/

# Perplexity-User is user-triggered and generally ignores robots.txt.
# If you want those fetches to succeed, allow the documented IP ranges in your WAF.

Warning: Blocking PerplexityBot can remove your pages from Perplexity's search and citation surface. It does not guarantee that a competitor will be cited instead.
