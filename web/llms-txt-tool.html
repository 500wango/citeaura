Frequently asked questions

What is an llms.txt file?

An llms.txt file is a markdown-formatted plain text file deployed at your site root or /.well-known/llms.txt that provides AI crawlers with concise entity definitions, key facts, and curated links to essential documentation.

Does publishing an llms.txt guarantee AI recommendations?

No. The file is a discovery aid that reduces extraction ambiguity, not a ranking guarantee. Answer engines evaluate full page content, third-party corroboration, and user context.

Where should the llms.txt file be hosted?

Host it at https://yourdomain.com/llms.txt or https://yourdomain.com/.well-known/llms.txt with content-type text/plain; charset=utf-8, and reference it in your robots.txt or HTML link headers.
