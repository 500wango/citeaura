Frequently asked questions

What is an llms.txt file?

An llms.txt file is a proposed Markdown convention at /llms.txt. It gives supporting agents concise entity definitions, verified facts, and canonical links. It is not a Google Search requirement, and Google Search does not use it.

Does publishing an llms.txt guarantee AI recommendations?

No. Some agents or crawlers may ignore the file. It is a discovery aid, not a ranking or citation guarantee.

Where should the llms.txt file be hosted?

Publish it at https://yourdomain.com/llms.txt with a successful text response. /.well-known/llms.txt is not required by the convention. robots.txt and link headers are not required to use the file.

Is llms.txt required for Google Search?

No. Google Search does not use llms.txt and does not require special AI text files or markup for AI Overviews or AI Mode.

What is the recommended size limit for llms.txt vs llms-full.txt?

Five kilobytes is practical editorial guidance, not a protocol limit. Keep the index short enough to scan and link to canonical pages for detail. Size and truncation behavior vary by client, so test with the agents you care about.
