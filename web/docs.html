Getting Started

5-Minute Quickstart Guide

CiteAura is a Generative Engine Optimization (GEO) platform that audits, measures, and helps improve your brand's citation and visibility across generative AI engines.

1

Create your workspace & add brand

Register at citeaura.com/app (no credit card required). Enter your official website URL (e.g. https://yourbrand.com) and optional brand display name. CiteAura will automatically crawl your site, extract brand facts, and initialize the diagnostic pipeline.

2

Connect 1~2 AI Model Probes (BYOK)

Navigate to Settings → Model Keys (BYOK). Paste your official OpenAI, DeepSeek, or Anthropic API key. Your keys are immediately encrypted at rest using AES-256-GCM.

3

Run GEO Diagnosis & Sampling

Click Run Full Diagnosis in the Overview or Workbench. CiteAura will analyze semantic extractability and simulate multi-turn prompt queries across the configured AI models.

4

Implement 13 Action Tickets & /llms.txt

Review detected Perception Gaps and download your generated /llms.txt file and structured JSON-LD schemas to deploy onto your web server.

5

Closed-Loop Verification & Trend Tracking

After deploying updates, run a verification sampling task in Verify to observe visibility improvements and confirm whether identified perception gaps are resolved.

The 5-Step Continuous GEO Loop

GEO is an ongoing optimization cycle rather than a one-time audit:

  1. Audit (诊断): Crawls domain pages to evaluate semantic extractability, WAF accessibility, and entity clarity.
  2. Diagnose (分析): Multi-model probe sampling measures brand mention rate, sentiment, and perception gaps.
  3. Plan (工单): Compiles 13 standardized engineering tickets prioritized by impact and difficulty.
  4. Deploy (落地): Provides machine-readable /llms.txt, structured metadata, and target citation channels.
  5. Verify (复测): Re-runs calibrated sampling to track visibility score progression over time.

GEO vs. Traditional Search SEO

Traditional SEO focuses on search engine ranking pages for keyword queries. Generative Engine Optimization (GEO) focuses on ensuring AI synthesis engines understand, cite, and recommend your brand when answering complex user prompts.

Dimension Traditional SEO Generative Engine Optimization (GEO)
Primary Target Search Engine Result Pages (10 Blue Links) Direct AI Answer Synthesis & Recommendations
Evaluation Metric Keyword Rankings, Organic Clicks, Backlinks AI Visibility Score, Mention Rate, Citation Share
Optimization Unit Webpage URL & Title Tags Brand Entity, Verifiable Facts, Fact Consistency
Crawler Targets Traditional Search Engine Bots AI Training Scrapers & Live Retrieval Bots
Core Deliverables Meta descriptions, Keyword Density, Backlinks /llms.txt, Schema JSON-LD, Citation Infiltration

How AI Models Recommend Brands

When an AI model is asked for product or service recommendations, its response is generated through two primary mechanisms:

  • Parametric Memory: Information absorbed during the model's pre-training phase, reflecting long-term entity associations and public documentation.
  • Live Web Retrieval: For connected models (such as Perplexity or live-browsing search engines), the model performs real-time searches and synthesizes content from high-authority review sites, discussion forums, and official fact sheets.

Why API Keys are "Probes", Not "Paid Ads"

Important Clarification: Configuring an AI model's API key does not alter the model's underlying weights or buy advertising placement.

The Role of BYOK (Bring Your Own Key):

  • Calibrated Measurement: CiteAura uses your provided API key to query the model with representative industry questions, measuring your brand's presence and accuracy.
  • Direct Cost Transparency: Queries are billed directly by the respective AI vendor at standard API rates, avoiding third-party token markups.

3 Sampling Modes Explained

Every visibility measurement in CiteAura clearly states its sampling source:

  • API · Model Knowledge (Parametric): Queries the model directly using its internal parameters without live web browsing.
  • API · Web-Grounded Retrieval (Live Search): Queries models that use real-time web search capabilities to synthesize answers.
  • Manual · Product Surface: Incorporates transcripts audited manually from consumer web interfaces.

BYOK Model API Key Setup Guides

Supported vendors include DeepSeek, OpenAI, Anthropic, Google, Zhipu AI, ByteDance, Moonshot AI, MiniMax, xAI, and Perplexity.

1. DeepSeek Setup

  1. Log into the DeepSeek Open Platform.
  2. Navigate to API Keys and create a new key.
  3. Paste the key into CiteAura under Settings → Model Keys (BYOK) → DeepSeek.

2. OpenAI Setup

  1. Log into the OpenAI Developer Platform.
  2. Generate a new secret key under API Keys.
  3. Paste into CiteAura under OpenAI.

3. Anthropic Setup

  1. Log into the Anthropic Console.
  2. Generate an API key and paste it into CiteAura under Anthropic.

Security & Zero Training Guarantee

All API keys are encrypted at rest with AES-256-GCM. CiteAura guarantees that customer data, audit results, and diagnostic queries are never used to train or fine-tune public AI models.

13 Standard Action Tickets Overview

CiteAura provides 13 standardized engineering tickets covering technical site readiness, brand entity clarification, and third-party citation building.

Deploying /llms.txt

/llms.txt is a clean Markdown standard that helps AI crawlers easily discover your core facts, features, and official links.

# Brand Fact Sheet > Summary of core capabilities, official offerings, and verified facts. ## Core Capabilities - Site-wide GEO semantic extractability audits - Multi-model perception gap diagnosis - 13 Standardized engineering tickets - Automated /llms.txt and JSON-LD schema generation - White-label delivery package compilation ## Official Endpoints - Website: https://yourbrand.com - Documentation: https://yourbrand.com/docs

Deploy this file directly to the root of your web server at https://yourbrand.com/llms.txt.

Citation Source Strategy

In the Channels (信源与渠道) dashboard, CiteAura lists the third-party websites and platforms most frequently referenced by AI search engines in your industry. By contributing quality information to these referenced domains, you increase the likelihood of inclusion during live web synthesis.

External Data Integrations

CiteAura connects with third-party tools to cross-reference search engine metrics with generative AI visibility.

Connect your TabAPI key under Integrations → TabAPI to track monthly domain visits, global rankings, and traffic source distributions.

2. Google Search Console

Authorize read-only access (webmasters.readonly) to monitor organic Google clicks, search impressions, and top search queries alongside AI visibility trends.

3. Semrush API

Configure a Semrush API key to benchmark domain authority scores and organic competitor keyword matrices.

Frequently Asked Questions

Why does an AI engine show "Unmeasured"?

If you have not connected an API key for a specific vendor, CiteAura marks that vendor as Unmeasured rather than displaying simulated or estimated values.

How do I export client delivery packs?

Go to Delivery → Client Delivery Packs and click Generate Delivery Pack to compile executive summaries, audit reports, and deployment assets for client handoff.
