GEO vs. Traditional Search SEO

Traditional SEO was built for a world of 10 blue links on Google. Generative Engine Optimization (GEO) is built for the new era where users receive synthesized AI answers, direct brand recommendations, and comparative tables.

Why API Keys are "Probes/Monitors", Not "Paid Ads"

Common Misconception: "If I configure OpenAI's API Key, will ChatGPT automatically mention my brand more?"

Answer: No. Commercial AI models (OpenAI, Anthropic, Google, DeepSeek) cannot be bribed or altered simply by passing an API key. Their weights and web retrieval algorithms are independent.

The Real Purpose of BYOK Keys:

  • The "Diagnostic Radar": CiteAura uses your API key as a calibrated probe to query the model on your behalf (e.g. "What are the top 5 tools for SaaS attribution?") and scientifically score how often and in what sentiment your brand appears.
  • Zero Middleman Markup: By using your own official key directly, each diagnostic query costs only a fraction of a cent (paid straight to OpenAI/DeepSeek), avoiding inflated token subscription surcharges.

The 3 Sampling Modes Explained

CiteAura enforces strict scientific truth in all measurement dashboards. Every citation and visibility score is tagged with one of three transparent sampling modes:

  • API · Model Knowledge (Parametric Memory): Tests what the AI model knows internally from its pre-training cutoff without active web searching.
  • API · Web-Grounded Retrieval (Live Search): Tests what the model recommends when live search browsing (Perplexity, GPT-4o Search, Claude Search) is triggered.
  • Manual · Product Surface: Captures direct user-facing prompt transcripts audited manually via web UI.

BYOK Model API Key Setup Guides

All API keys are encrypted at rest using isolated AES-256-GCM envelopes. We uphold a strict Zero Model Training Guarantee: your queries, keys, and brand facts are never used to train public AI models.

1. DeepSeek API Key Setup

  1. Visit the official DeepSeek Open Platform (platform.deepseek.com).
  2. Log in, navigate to API Keys, and click Create new API key.
  3. Copy the sk-•••••••• key and paste it into CiteAura at Settings → Model Keys (BYOK) → DeepSeek.

2. OpenAI (ChatGPT / GPT-4o) API Key Setup

  1. Visit the OpenAI Developer Platform (platform.openai.com).
  2. Click Create new secret key, assign permissions, and copy the key.
  3. Paste into CiteAura under OpenAI.

3. Anthropic Claude API Key Setup

  1. Visit Anthropic Console (console.anthropic.com).
  2. Navigate to API Keys and generate a live key.
  3. Paste into CiteAura under Anthropic.

Frequently Asked Questions

Why does an AI engine show "Unmeasured" in my matrix?

CiteAura does not fake or simulate arbitrary scores. If you have not configured an API key for a specific engine (e.g. Claude), that column is marked honestly as Unmeasured rather than misleadingly displaying 0%.

How do I export white-label delivery decks for agency clients?

Navigate to Delivery → Client Delivery Packs. Click Generate Delivery Pack. CiteAura will compile executive Markdown summaries, audit PDFs, before-and-after visibility comparisons, and custom branded deliverables in one package.
