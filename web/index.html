06 / 常见问题

开始之前

API 采样能代表用户在网页端看到的答案吗？

多数 API 测量的是模型参数化知识，并不等于产品端实时搜索。DisvorAI 会在每个引擎旁标明 API·参数化知识、API·联网检索或人工·产品端。

必须提供自己的模型 API Key 吗？

BYOK 是默认方式。你只需要配置计划使用的引擎，未配置的引擎会跳过并显示“未测”。

结果能保证品牌被 AI 提及吗？

不能。产品提供可追溯诊断、执行建议和前后对比，不承诺排名或提及。回答有噪声，需要用多轮趋势判断变化。

14 天试用包含什么？

试用支持 3 个项目，每个项目最多运行 2 次采样，并可使用报告、工单、验收和交付包。

适合代理商交付客户吗？

适合。Agency 提供 30 个活跃项目、团队角色和白标交付页眉，交付包可下载归档。
