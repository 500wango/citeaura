06 / FAQ

Before you start

Do API samples match what users see in the product UI?

Most APIs measure model knowledge, not live product search. DisvorAI labels each engine as API · Model knowledge, API · Web-grounded retrieval, or Manual · Product surface.

Must I bring my own model API keys?

BYOK is the default. Configure only the engines you plan to use; others are skipped and shown as unmeasured.

Can results guarantee the brand is mentioned by AI?

No. The product provides traceable diagnosis, execution guidance, and before/after comparison—not ranking or mention promises. Answers are noisy; use multi-round trends.

What is included in the 14-day trial?

The trial supports 3 projects, up to 2 sampling runs each, plus reports, tickets, verification, and delivery packs.

Is it suitable for agency client delivery?

Yes. Agency includes 30 active projects, team roles, white-label headers, and downloadable packs.
