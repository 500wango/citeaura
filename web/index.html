你需要知道的一切

API 样本是否匹配用户在产品 UI 中看到的内容？
大多数 API 测量的是参数化模型知识，而非实时产品搜索。CiteAura 明确标记每个引擎为「API · 模型知识」、「API · Web 检索」或「手动 · 产品界面」，以确保完整的科学严谨性。
我必须自带模型 API 密钥（BYOK）吗？
BYOK 是最安全且最具成本效益的方法。你只需配置打算使用的引擎；其他引擎会诚实显示为"未测量"。模型 API 非常实惠（单次审计通常成本约 $0.08-$0.15），无中间商加价。
CiteAura 能保证我的品牌被 AI 提及或排名吗？
不能。任何承诺保证 AI 推荐的供应商都不诚实。CiteAura 提供严格的诊断、标准化工程票据和可重复的验证证据，帮助团队随时间改进可见性。
7 天免费试用包含什么？
7 天免费试用包含试用工作空间配额：3 个项目、每个项目 2 次采样运行、完整报告、行动票据和交付包，无需信用卡。
