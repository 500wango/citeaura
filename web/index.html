06 / FAQ

Frequently asked questions

Do API samples match what users see in the product UI?

Most APIs measure parametric model knowledge, not live product search. CiteAura clearly labels each engine as API · Model knowledge, API · Web-grounded retrieval, or Manual · Product surface for complete scientific integrity.

Must I bring my own model API keys (BYOK)?

BYOK is the most secure and cost-effective method. You only configure the engines you intend to use; others are honestly shown as unmeasured. Model APIs are extremely affordable (single audits typically cost ~$0.08–$0.15) with zero middleman markup.

Can CiteAura guarantee my brand will be ranked or mentioned by AI?

No. Any vendor promising guaranteed AI recommendations is untruthful. CiteAura provides rigorous diagnosis, 13 standardized engineering tickets, and before/after verification to maximize your recommendation probability with deterministic optimization.
