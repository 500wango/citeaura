Frequently asked questions

Do API samples match what users see in the product UI?

Most APIs measure parametric model knowledge, not live product search. CiteAura clearly labels each engine as API · Model knowledge, API · Web-grounded retrieval, or Manual · Product surface for complete scientific integrity.

Must I bring my own model API keys (BYOK)?

Model usage is separate from your subscription. With your own API keys, model providers bill you directly. Review any platform-funded budget before sampling.

Can CiteAura guarantee my brand will be ranked or mentioned by AI?

No. Any vendor promising guaranteed AI recommendations is untruthful. CiteAura provides rigorous diagnosis, standardized engineering tickets, and repeatable verification evidence to help teams improve visibility over time.

What is included in the 7-day free trial?

The 7-day free trial includes the trial workspace allocation: 3 projects, 2 sample runs per project, full reports, action tickets, and delivery packages with no credit card required.

Is CiteAura suitable for digital marketing agencies delivering to clients?

Absolutely. The Agency plan is tailored for agencies with 30 active projects, team role permissions, white-label client headers, and downloadable client-ready delivery packs.
