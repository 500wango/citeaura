Why ChatGPT Does Not Mention Your Brand

A missing mention has several possible causes, and the chat window does not tell you which one you are looking at. Check crawl access, initial HTML, bot challenges, and the public fact record before changing copy. Then repeat a labeled cohort so a noisy answer is not mistaken for a site defect.

The 4 buckets — pick one before you edit

When a brand is missing from an answer, start by naming the failure mode. In practice the useful first pass is four buckets; each points to a different owner and a different check.

BucketSignal in logs/auditFix owner
1. Crawl accessGPTBot Disallow on /, /pricing, /docsInfra / SEO
2. ExtractabilityView-source shows <div id="root"></div> + 380KB JSFrontend
3. WAF / challenge403 / JS challenge for unknown UA; OK for browserSecurity
4. Thin factsNo H1 definition, no pricing, PDF-only comparisonContent / PMM

If the brand appears in one answer and disappears in the next with the same questions and mode, add a fifth label: sampling variance — not a site defect.

Bucket 1: Crawl access — is GPTBot allowed to fetch the pages that define you?

Fetch the live file on the canonical host. A staging copy or CDN cache lies.

curl -s https://citeaura.com/robots.txt | cat
curl -A "GPTBot/1.0" -s -D - https://citeaura.com/ -o /dev/null | head -n 20
curl -A "OAI-SearchBot/1.0" -s -D - https://citeaura.com/pricing -o /dev/null | head -n 20

Match rules: longest path wins, User-agent: GPTBot group is evaluated before *, groups do not merge. A Disallow: / under * still blocks GPTBot unless an explicit GPTBot group Allows it. See the companion guide GPTBot Blocked by robots.txt — Find and Fix the Rule for full precedence and Caddy/Cloudflare cache pitfalls.

Ticket evidence: attach the fetched robots.txt snippet + the Allow/Disallow line that matched, plus the canonical host you tested (apex vs www).

Bucket 2: Extractability — does the product definition exist in initial HTML?

Open view-source:https://citeaura.com/ (not Inspect). If the one-sentence definition, pricing, and differentiators only appear after JS hydrates, many crawlers see an empty shell.

# Compare raw HTML vs rendered
curl -s https://citeaura.com/ | grep -i "Generative Engine" | head
# or: save raw and count visible text
curl -s https://citeaura.com/ | sed -n '1,200p' | wc -c
# In browser: View Source should contain the H1/H2 and pricing table as HTML, not as JS string

Fix pattern: server-render the hero H1, pricing table, and comparison block; keep the app shell for /app/* only. Verify by re-curling after deploy — the H1 must be in the first 15KB of HTML.

CheckPassFail → ticket
H1 definition in view-sourceExact sentence in HTMLMove to SSR / SSG
Pricing table<table> with pricesRender server-side
Comparison copyHeadings + prosePublish page, not PDF

Bucket 3: WAF / challenge — human sees content, bot sees 403

A Cloudflare Managed Challenge or enterprise WAF can serve a JS challenge to unknown UAs while browsers pass. Symptom: homepage renders for you, but curl -A GPTBot gets 403 or a challenge page.

curl -s -D - https://citeaura.com/ | head -n 15
curl -A "GPTBot/1.0" -s -D - https://citeaura.com/ | head -n 15
# Look for: HTTP/2 403, cf-mitigated: challenge, or body containing "Just a moment"
curl -s https://citeaura.com/ | grep -i "challenge\|cf-ray" | head

Fix: allowlist the public marketing paths (/, /pricing, /docs, /blog/*) to Bypass for verified bots, or configure Bot Management to allow GPTBot/OAI-SearchBot/PerplexityBot by UA. Never bypass /app or /admin.

Bucket 4: Thin or inconsistent facts — nothing stable to cite

Even with perfect crawl and extractability, a model has nothing to cite if official facts are thin, inconsistent, or locked in PDFs.

Pricing$79/$199/$499Missing$79Inconsistent → ticket

For a claim to be retrievable, publish it as HTML prose on a public route with a stable URL. A sales deck can support a conversation, but it is not a dependable retrieval surface.

Variance vs defect — when not to rewrite

Avoid reacting to a single chat. Repeat the same 10–20 questions, same market/language, same sampling mode (API · Model knowledge vs API · Web-grounded retrieval vs Manual · Product surface). Compute mention rate as mentioned / successful per cohort. See How to Measure ChatGPT Brand Mentions for cohort and Wilson interval method.

  • Variance: 3/15 one day, 9/15 next day on same cohort → inspect cohort size, increase n to 45, then re-evaluate.
  • Defect: 0/45 across 3 runs with stable questions → go to buckets 1–4 and open tickets.

Why competitors can be easier to cite

Category prompts (“best tools for X”) reward brands that already answer that sentence in public HTML plus supporting pages: comparison tables, third-party listings (G2/Capterra), and docs. If a competitor has a clear H2 “Best AI Visibility Tools — Comparison” and you have a PDF, the model has a citable path for them and a dead end for you. Publish a comparison page in HTML, not as a gated asset.

Anonymized teardown

Anonymized example: two B2B tools were tested against the same “AI visibility tool” cohort. One exposed its definition only after hydration and kept pricing in a gated PDF; the other had plain HTML, a pricing table, and a public comparison page. Across 15 questions × 3 runs (45 samples, API · Model knowledge), the first appeared 2 times (4.4%) and the second 19 times (42.2%). After the first site published a server-rendered hero and comparison page, a repeat cohort reached 11/45 (24.4%). This is an illustration of what extractability can change, not a CiteAura customer benchmark or a ranking promise.

What to publish so you are citable

  • Category answer page: one HTML page that literally answers “best tools for [your category]” with a headed table (columns: tool, best for, pricing, citation URL). Each row links to a public source you control or to a third-party listing.
  • Comparison page: “CiteAura vs X” in plain HTML with an H2 per differentiator and a prose paragraph, not just a feature tick grid. Models quote sentences, not checkmarks.
  • Third-party footprint: keep accurate profiles on relevant directories such as G2, Capterra, or AlternativeTo. They can corroborate your own pages, but there is no fixed listing count and no mention guarantee.

Anti-pattern: hiding the comparison in a gated PDF or Notion embed. If a URL requires a click to “Download PDF” with no HTML fallback, treat it as invisible for retrieval.

Field checklist — collect before you open a ticket

Attach these to the ticket so the reviewer does not have to guess:

  1. Fetched robots.txt snippet + matched Allow/Disallow line + canonical host tested.
  2. View-source excerpt showing (or missing) H1, pricing table, and comparison headings — include byte offset and curl command used.
  3. curl -A GPTBot response header (200 vs 403/challenge) and any cf-mitigated header.
  4. Fact-consistency matrix row for the claim you want cited (homepage / docs / JSON-LD).
  5. Cohort definition: question hashes, sampling mode, dates, and mention_rate with n.
  6. Before/after diff link (git or CMS) for the HTML fix so verification can point to the commit.

Decision tree — what to do next in 10 minutes

1) curl robots.txt → GPTBot Disallow on public paths? → fix robots (Bucket 1)
2) view-source has H1/pricing? no → SSR/SSG fix (Bucket 2)
3) curl -A GPTBot returns 403/challenge? yes → WAF bypass on public paths (Bucket 3)
4) Facts inconsistent across HTML/docs/JSON-LD? yes → align facts (Bucket 4)
5) else → repeat cohort n=45, check variance before editing

How CiteAura turns this into tickets

The site audit maps each failure to a ticket with owner, severity, and an acceptance check (for example, “curl -A GPTBot returns 200 and the H1 is present in view-source”). After deployment, Verify re-crawls the public pages and records whether that check passes. A new AI sample is separate; a passed crawl check is not a mention count.

FAQ: why ChatGPT skips a brand

Does allowing GPTBot guarantee a ChatGPT mention?

No. It removes one crawl block. The page must still be extractable and the question must require the brand.

Is llms.txt enough to make a brand appear?

No. It is an optional summary. The public HTML must already state the facts.

When is a missing mention a measurement issue?

When the same cohort varies answer-to-answer. Use n≥45 and a labeled sampling mode before calling it a site defect.

Should I rewrite after one missing mention?

No. Repeat the cohort, run the 4-bucket checks, then write a ticket with evidence.
