Crawl access

GPTBot Blocked by robots.txt? Find and Fix the Rule

GPTBot is blocked by robots.txt when a Disallow rule matches the paths that state your product. Open the file at the site root, find the User-agent for GPTBot or a blanket * rule, and allow the public pages you want retrieved. After you deploy, request the file again and confirm the crawl. CiteAura flags blocked AI crawlers in the site audit so the fix is a ticket, not a guess.

Updated 20 August 2026 · 6 min read

By CiteAura Editorial Team · Evidence and documentation

How to tell that GPTBot is blocked

Fetch https://yourdomain.com/robots.txt in a browser or with curl. Look for a group that names GPTBot, OAI-SearchBot, or ChatGPT-User, and for a User-agent: * group that Disallows / or the marketing paths. The first matching group for that crawler wins.

A WAF challenge or a login wall can look the same as a robots block in a later model answer. Fix robots first because it is the cheapest, explicit signal.

How to fix the file

  1. Keep Disallow on private app, admin, cart, and API routes.
  2. Allow the homepage, product, pricing, docs, and other pages that state official facts.
  3. Add an explicit GPTBot group if a blanket * rule is too coarse to edit safely.
  4. Deploy to the canonical host, including the www or apex redirect you actually use.
  5. Fetch the live file again. Do not trust a staging copy or a CDN cache you have not purged.

A minimal public allow looks like this:

User-agent: GPTBot
Allow: /
Disallow: /app/
Disallow: /admin/

Allowing GPTBot is not a mention switch. It only removes a crawl block. Retrieval and answers can still skip the brand.

Related crawlers to check at the same time

  • OAI-SearchBot and ChatGPT-User — OpenAI search and in-product browsing.
  • ClaudeBot, PerplexityBot, Google-Extended — other training or retrieval agents you may want on public pages.
  • A sitewide Disallow: / — often copied from a staging template and left on production.

If the homepage is a JavaScript shell, opening robots is not enough. See Why ChatGPT Does Not Mention Your Brand for extractability checks after the crawler is allowed in.

A crawl allow is not a ranking promise

Opening robots.txt lets a crawler request the page. It does not guarantee that ChatGPT will fetch, mention, cite, or rank the brand. Treat the fix as a prerequisite, then measure with a labeled cohort.

FAQ: GPTBot and robots.txt

Should GPTBot be allowed to crawl every route?

No. Keep app, admin, account, cart, API, and other private routes closed. Allow only public pages that state the product.

How do I confirm a GPTBot robots.txt fix?

Fetch the live robots.txt file on the canonical host after deployment, clear any relevant cache, and re-crawl the public pages.

Will an allowed crawler guarantee a ChatGPT mention?

No. An allow rule removes a crawl block; it does not guarantee retrieval, a citation, a mention, or a ranking.
