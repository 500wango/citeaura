Discovery file

What to Put in llms.txt for Your Brand

Put only official, checkable facts in llms.txt: who the brand is, the canonical URL, a one-sentence product definition, and links to public pages that already state those claims. Skip slogans, unverified rankings, and copy that exists only in a PDF. CiteAura can draft the file from the brand fact library, but you still review every line before you publish it at the site root.

Updated 20 August 2026 · 6 min read

By CiteAura Editorial Team · Evidence and documentation

What belongs in the file

  • Brand name and one-sentence definition that already appears in public HTML.
  • Canonical site URL and a short list of official pages: product, pricing, docs, contact.
  • Verified facts with a source page you control, such as markets served or plan names.
  • Plain Markdown served as text/plain at https://example.com/llms.txt.

Keep it short. A crawler that already struggles with a JavaScript homepage will not be helped by a 2,000-word manifesto.

What to leave out

  • Awards, traffic claims, or “#1 in AI search” lines you cannot point to on an official page.
  • Pricing or feature lists that disagree with the live pricing page.
  • Competitor attacks that are not factual comparison copy you would publish elsewhere.
  • Private app routes, staging hosts, or login-walled docs.

/llms.txt is a discovery convention, not a universal index. A 200 response proves the file is reachable. It does not prove a model read it.

A safe skeleton

Start from this shape and delete any line you cannot support:

# Brand Name
> One-sentence, verifiable description.

## Official resources
- Product: https://example.com/
- Docs: https://example.com/docs

## Verified facts
- Fact that already appears on a public page, with that URL.

If GPTBot cannot reach the homepage, fix robots first. See GPTBot Blocked by robots.txt? Find and Fix the Rule.

Publishing llms.txt does not guarantee mentions

A clean file can help a retrieval-enabled sample find official wording. It does not guarantee that ChatGPT, or any other model, will mention, cite, or rank the brand. Treat it as one official summary next to the HTML that already has to be extractable.

FAQ: publishing llms.txt

What should not go in llms.txt?

Leave out private routes, staging URLs, login-only content, credentials, and claims that are not supported by an official public page.

Does llms.txt guarantee AI mentions?

No. It is an optional discovery convention. A reachable file does not prove that a model read it or will mention the brand.

Where should llms.txt be published?

Publish it as plain text at the canonical site root, for example https://example.com/llms.txt, and keep its links public.
