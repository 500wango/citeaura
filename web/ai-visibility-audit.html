What an AI visibility audit should check.

A useful audit separates the source you control from the answers you observe. That keeps a crawl problem, a missing official fact, and ordinary model variance from being collapsed into one unexplained score.

01 · Reach

Can the source be found?

Review canonical URLs, robots rules, sitemaps, llms.txt, rendered HTML, and the page links that define the public source.

02 · Extract

Can the facts be understood?

Check the product definition, pricing, structured data, official claims, and page structure that make a brand easy to identify and quote.

03 · Measure

Does the answer contain evidence?

Use a fixed question set and provider cohort. Keep raw answers, mentions, citations, sample coverage, and sampling mode attached to the result.

How to run an AI visibility audit.

01

Define the buyer questions

Start with category, comparison, recommendation, pricing, and problem questions a real buyer could ask. Keep brand probes separate.

02

Crawl the canonical public site

Record what a crawler can reach and what the initial HTML exposes before changing copy or adding generated assets.

03

Sample a defined provider cohort

Label API model knowledge, web-grounded retrieval, and manual product-surface observations separately. Missing coverage remains unmeasured.

04

Turn gaps into owner-ready tickets

Prioritize the smallest useful page, fact, schema, or crawl change with an acceptance condition that someone can verify.

05

Re-crawl and re-sample the change

Compare the same source, questions, cohort, and measurement window. A changed answer is evidence for that scope, not a universal guarantee.

AI visibility audit questions.

What is an AI visibility audit?

It checks whether a public website exposes the pages and official facts that AI systems can reach, extract, retrieve, and cite for a defined question set.

Does an AI visibility audit replace traditional SEO?

No. Traditional SEO and AI visibility audits answer different questions. Use both when you need search traffic and evidence about how AI answers describe a brand.

Can I start without a model API key?

Yes. Start with a public technical audit. Model sampling is a separate, explicitly labeled evidence stream that can be added later.

What does a passing audit prove?

It proves that the defined checks passed for the recorded source and time window. It does not guarantee a future ranking, mention, or citation.
