
# CiteAura 商业化评估

日期：2026-09-13。范围：onboarding、试用、付费墙、套餐权益与定价。结论基于当前代码、PRD、产品页面和公开竞品资料；不代表线上转化结果。

## 结论

CiteAura 最适合的商业化路径是“免费完成一次可行动的 AI 可见性诊断，付费获得持续监测、复测告警、规模化项目管理和客户交付证据包”。现有价格层级已有市场锚点，Agency 的白标交付是最清晰的付费价值。暂不建议立即改价或把首个诊断硬墙化，先验证首个诊断结果之后的升级提示。

## 当前路径

注册后进入 onboarding（`web/app/views/onboarding.js`）：输入官网 URL、运行预检、选择 Audit only 或 Full AI baseline、创建项目并运行异步管线，最后查看审计、采样、工单、验证和交付包。Audit only 不需要模型 API Key，能先交付抓取、事实、工单和诊断报告，这是主要激活优势。

Trial 为 7 天、最多 3 个项目、每项目最多 2 次采样（总计 6 次）。过期后阻止创建项目和采样；付费计划 sample runs 当前无限。注册、首个项目、首个审计、首个采样、首个交付包、首次复测和 checkout 事件已有记录入口，但没有真实 cohort 数据。

当前套餐：Starter $79/月、3 个活跃项目；Pro $199/月、10 个项目、定时重采样和下降告警；Agency $499/月、30 个项目、白标交付和团队权限；Enterprise 定制价，含私有部署、SLA、OIDC SSO、数据保留和专属支持。年付约 16.67% 折扣。白标与客户发送链接确实限制在 Agency/Enterprise，OIDC SSO 只在 Enterprise。BYOK 优先，模型费用与订阅分开。

## 优先问题与建议

1. **付费价值出现太晚。** 试用已含报告、工单和交付包，AI baseline 又需要 Key。保留首个 Audit only，在结果页根据证据展示“安排持续复测”“下降时告警”“解锁白标交付包”等上下文 CTA。
2. **Starter 文案可能误导。** “13 standard action tickets & verification runs”更像诊断生成结果，不是套餐额度。改为“每次诊断生成约 13 个标准化行动项（以项目结果为准）”，或删除数字。
3. **Pro 的“无限 BYOK sampling”不够像购买理由。** 购买前应优先解释监测项目数、复测频率、告警、证据历史和团队协作，并明确平台池、调用量、预算和按量成本。
4. **Agency 应按交付效率销售。** 保留 30 项目作为容量证据，主文案强调多客户复用、白标包和客户链接带来的交付效率。
5. **试用过期后的历史结果。** 可以阻止新增项目和采样，但应继续让用户读取已完成报告、工单和交付包，并在受限动作旁说明升级后恢复什么。代码已证明创建/采样会受限，历史结果可读性仍需运行验证。

## Onboarding 与付费墙

首屏可用文案：“先看一次真实诊断，再决定是否接入 AI 采样。”说明 Audit only 无需 Key，Full AI baseline 需要 BYOK 或平台池。

结果页先展示一个可行动发现：问题、证据来源、影响和建议动作。Audit only 用户主 CTA 为“安排持续复测”（Pro）；需要客户交付者为“解锁白标交付包”（Agency）；需要平台代付者进入带用量和预算说明的 Key 池流程。跳过升级仍可完成当前项目，下一次采样或定时监测触发时再提示。

不在首次打开或首个 audit 前硬墙。把持续复测、下降告警、跨项目容量、平台池、白标和 SSO 做功能门槛，并显示当前结果、被锁定的下一步、对应套餐、订阅价格、年付价格和模型调用费用边界。

## 套餐与竞品锚点

| 套餐 | 价格 | 适合用户 | 应突出权益 |
|---|---:|---|---|
| Trial | 7 天免费 | 首次评估 | 3 项目、每项目 2 次采样、报告/工单/交付包 |
| Starter | $79/月 | 单品牌/独立顾问 | 3 项目、基础报告与交付包，明确复测和平台池边界 |
| Pro | $199/月 | 持续监测团队 | 10 项目、定时复测、下降告警、证据历史、协作 |
| Agency | $499/月 | 多客户团队 | 30 项目、白标交付、客户链接、团队权限 |
| Enterprise | 定制 | 高安全/规模组织 | 私有部署、SLA、OIDC SSO、数据保留、专属支持 |

Otterly.ai 官方页显示 Lite $29/月、Standard $189/月、Premium $489/月，按 search prompts 计量；Ahrefs Brand Radar 官方页显示起价 $199/月，另一档 $699/月并按 checks 计量。CiteAura 的 Pro/Agency 与持续监测产品接近。Peec AI、Profound 本次未取得可靠具体价格，不据此推断。首轮保持现价，待完整试用 cohort 后再讨论额度或定价。

## 实施与验证

P0：结果页增加持续监测/复测/白标上下文 CTA；修正 Starter 文案；统一 BYOK、平台池和模型费用说明；确认历史结果可读；记录 CTA 曝光、点击和 `checkout_started`。P1：按 solo/品牌方与 agency/顾问分流叙事，保持价格不变。P2：有数据后再讨论采样额度、复测频率和平台池按量计费。

首轮假设：完成 audit-only 后展示持续监测/复测/告警/交付包提示，比注册后直接展示完整套餐更能推动购买。保持价格、权益和支付流程一致，按 solo 与 agency 分组。主指标为 `first_audit → checkout_started`、`checkout_started → checkout_succeeded`、成熟试用 cohort 的 `trial → paid`，以及 renewal、cancel、refund。辅助指标包括 signup → project_creation、project_creation → first_audit、first_audit → first_evidence、first_audit → first_resample。试用开启不算付费，分母、去重、地区和观察窗口需固定。当前没有 cohort 基线，不能给出提升百分比或收入预测。

## 事实限制

代码能证明套餐门槛、路由和事件入口，不能证明价格最优、付费意愿、转化率、留存或收入规模。本次未执行真实支付、线上 cohort、第三方模型调用或生产浏览器验证。公开竞品价格按 2026-09-13 抓取结果记录，发布前应再次核对。
