# RankMax（rankmax.com.au）竞争能力核验

**检索日期：** 2026-09-04  
**范围：** 仅使用 RankMax 官方网站公开页面；“未发现”表示在所列官方页面未看到该能力的明确说明，不代表能力不存在。

## 结论

RankMax 是明显的 GEO/AI SEO 服务竞争者，且已公开覆盖 AI 引用测量、技术/内容/竞争审计、策略与执行。它更像“由团队交付的 AI SEO agency”，而不是公开售卖一个与 CiteAura 完全同构的证据驱动工作流 SaaS。

| CiteAura 能力 | 官网证据 | 判断 |
|---|---|---|
| AI 引擎采样与可见性测量 | AI Mode 页面称每月对 Google AI Mode、ChatGPT、Perplexity、Microsoft Copilot 做 **monthly manual spot-checks**，并按 URL、平台、查询主题记录引用；ChatGPT 页面还写有 prompt coverage mapping。 | **部分重合**：有跨引擎检查和引用记录，但公开表述是人工抽查/监控工作流，未证明参数化 API 采样、原始回答留存或可复现实验。 |
| 多维体检（含 6 维） | AI Mode 页面提供 technical/content audit，覆盖 structured-data gaps、content-authority shortfalls、citation-opportunity mapping；服务页称初始 audit 为 technical、content、competitive。Technical SEO 页面还列 crawlability、indexation、speed、schema、Core Web Vitals、internal linking、site architecture。 | **重合但非同一产品定义**：体检维度丰富，但未公开“6 维”固定模型、统一评分或页面级证据数据结构。 |

## 对 CiteAura 的竞争判断

建议将 RankMax 标记为 **高相关 GEO/AI SEO 服务竞争者（约 8/10）**，但不是“已证明拥有完整同构引擎”的竞争者。最清晰的差异化空间仍是：保留原始 AI 回答和引用证据、把诊断映射成带验收标准的工程工单、自动复测/回归重开，以及可审计的白标交付包。
