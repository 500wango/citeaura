# CiteAura v2.1 指标口径

## 北极星指标

**每月已见效改动数（Monthly Effective Changes, MEC）**

- 定义：同一自然月内，效果工单从 `observing` 进入 `effective` 的次数。
- 只统计观察期已结束、目标题与对照题均有足够簇、区间下界超过 `min_effect` 的工单。
- `inconclusive` 不计入，也不在对外文案中折算为“可能有效”。
- 同一工单重开后的再次生效可重复计数，但必须保留工单 ID 与证据卡链接。

## 激活指标

| 指标 | 口径 |
|---|---|
| 注册 → 首项目 | 创建至少一个未归档项目的租户 / 注册租户 |
| 首项目 → 首次采样 | 完成至少一次真实采样（`no_sample` 管线不计） |
| 首次采样 → 首个交付包 | 生成过 `delivery/` 包的租户 |
| 试用第 7/14 天复测 | 试用项目按计划完成自动复测的比例，写入 `trial_retests_json` |
| 14 天试用转化 | 试用到期后 7 天内进入 starter/pro/agency 的租户比例 |

## 质量指标

| 指标 | 口径 |
|---|---|
| 采样失败率 | `failed / total`，按引擎与采样模式分层；拒答、超时单列 |
| 区间半宽 | 题级簇 bootstrap 95% 区间半宽；30 题 × 5 轮目标 ≤ 8pp |
| 样本不足比例 | 返回 `insufficient_samples` 的题目 / 已测题目 |
| 效果判定分布 | effective / ineffective / inconclusive 工单数，按套餐分组 |
| 交付质量门禁 | `validate_delivery_quality` 未通过的包占比 |

## 商业指标

| 指标 | 口径 |
|---|---|
| MRR | 活跃订阅的月度等值收入，USD 口径 |
| Trial → Paid | 试用租户在到期后 7 天内首次付费的比例 |
| 平台池成本占比 | `platform_cost_cny_fen / MRR 折算成本`，按周监控 |
| 白标交付使用率 | Agency 租户中生成过白标交付包的占比 |
| 毛利率 | (MRR − 模型成本 − 基础设施) / MRR；按自然月结算 |

## 终止与下线条件

- 某引擎连续 30 天采样成功率 < 70%，从默认平台列表移除并标记 `canary.status=failed`。
- 效果验证的 A/A 误判率连续两个季度 > 5%，停止对外宣称“效果判定”，回退为 `beta` 并只展示区间。
- 某项宣称在 `scripts/check_claims.py` 中持续失败，视为发布阻断，不得上线。

## 数据来源

- 指标计算优先读取可重建投影表（`prompt_projections/run_projections/sample_projections`）。
- 投影与文件系统不一致时，以 `work/<tenant>/<slug>/` 为准并触发重建。
- 所有对外数字必须能下钻到样本行、Prompt、引擎版本、采样模式和时间戳。

## 本版明确延后

- 项目目录 UUID 化：需改所有引擎 slug 调用；本版用 `realpath` 防穿越 + 租户配额。
- 无头浏览器/第三方数据源的产品端自动采样：需条款与成本评估。
- 中文交付文档全量翻译：本版报告与题库语言可配置，交付模板先支持 en/zh 标签。
- 供应商调用级幂等键：本版依赖确定性 `run_id` + Job 幂等；硬杀重投仍可能重复计费，已在风险清单登记。
