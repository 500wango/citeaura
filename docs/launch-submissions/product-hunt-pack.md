## Description (first-comment length)

CiteAura is evidence-based GEO software. Paste a public domain. It audits crawlability and extractable facts, samples configured AI engines with an explicit sampling mode on every row, turns gaps into engineering tickets with acceptance criteria, then re-crawls and re-samples so you can see whether the change held.

It does not promise rankings or citations. Unmeasured providers stay unlabeled.

Built for brands and agencies that need a diagnostic loop, not another mention dashboard.

## First hunter comment (maker)

We built CiteAura because “are we in ChatGPT?” is the wrong question. The useful question is: can the model even read the page, which facts conflict, and did the ticket we shipped change mention_rate on a frozen cohort.

If you try it: run the public audit first (no key). Then connect BYOK only for the engines you actually need. Every sample is tagged API·parametric, API·web-grounded, or manual·product surface.

Happy to walk through a live domain in the comments.
