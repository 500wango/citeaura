# Editorial Judgment

Use this reference for long-form or already competent text. The goal is to choose the smallest intervention that materially improves the writing.

## Intervention ladder

### KEEP
Use when the block is already clear, precise, natural, or functionally important.

Typical examples:
- code, formulas, schemas, tables, API literals;
- concise technical explanations;
- distinctive author observations that are supported by the source;
- headings or checklists that materially aid navigation or execution.

### LIGHT
Use when the issue is local rather than structural.

Typical fixes:
- remove one filler phrase;
- replace one inflated abstraction;
- fix a repeated sentence opening;
- merge two near-duplicate sentences without changing the paragraph's role.

### EDITORIAL
Use when content is sound but presentation is over-produced.

Typical signals:
- too many verdict sentences in a row;
- repeated warning/lesson cadence;
- several paragraphs make the same point in slightly different language;
- every section has the same rhetorical shape;
- prose is technically correct but uniformly dense and polished;
- an article feels longer than the information requires.

Typical fixes:
- trim 5–20% selectively;
- merge warnings;
- vary section shapes;
- remove explanatory bridges;
- preserve useful scaffolding while cutting ceremonial prose.

### STRONG
Use when the block's underlying structure is weak.

Typical signals:
- generic opening with no concrete point;
- padded summary-like prose;
- vague benefit language;
- repetitive structure that prevents emphasis;
- paragraph order obscures the main idea;
- sentences can be deleted or rebuilt without information loss.

### MERGE-DELETE
Use only when the material has no distinct function.

Before deleting, check whether the material serves a separate reader task such as FAQ retrieval, checklist execution, compliance clarity, summary scanning, or search intent coverage.

## Escalation rule

Start with the least aggressive category that can solve the problem. Escalate only when a lower intervention would leave the underlying issue intact.

Do not use Strong merely because the user asked to "humanize" without specifying intensity. Mature content often needs Editorial, not reconstruction.

## Whole-document balance

For a strong technical or professional article, it is normal for many blocks to be KEEP or LIGHT. Visible change is not the objective.

A plausible intervention map may look like:

- KEEP 40–70%
- LIGHT 10–30%
- EDITORIAL 10–30%
- STRONG 0–20%
- MERGE-DELETE 0–10%

These are not quotas. Never modify text to fit a percentage.
